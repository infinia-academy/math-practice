ENVIRONMENT NOTE
The execution sandbox blocks Chromium from navigating to localhost/HTTP URLs directly.
The browser interaction test therefore loaded the exact production HTML/CSS/JS/data into
Chromium as static content and exercised the same client-side logic, while separate local
HTTP checks verified /math-practice/ path resolution and data retrieval. The production
HTML uses the official KaTeX CDN; the sandbox browser test used a KaTeX-compatible render
shim to exercise the app's rendering integration because external browser networking is
blocked in this environment.
