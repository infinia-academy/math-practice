Infinia Math Practice v3 - Adaptive Braindrops QA

Automated checks performed before packaging:
- JavaScript syntax checks for app.js and braindrops.js.
- Programmatic pool generation checked for every A1-A13 / M1-M9 level.
- Every generated question has an ID, level code, finite numeric answer, and non-empty prompt.
- Rolling history code is capped at 10 records per strand via slice(-10).
- Adaptive route and legacy Focus routes are both present.
- Relative static asset paths remain GitHub Pages project-site compatible.
- Brain expression CSS prevents arbitrary word wrapping; long derived expressions use explicit equation segments.
- Existing normal Math Practice routes/code remain in place.

Adaptive design:
- First game begins at A1 or M1 and can move upward after 4 fluent correct results at/above the frontier.
- With history, 30% of selection attempts target weakness review; 70% target current fluency/progression.
- Review weights increase for repeated errors and lower prerequisite levels.
- Three misses around/below the frontier can ease the frontier; a miss also slows remaining drops.
- Question pool is cached in localStorage with pool version 2; a small first-party cookie records pool version metadata.

Note: wrong keypad entries are stored as board-level wrong-entry events because the Raindrops-style mechanic does not identify which visible brain the learner intended. Question-specific incorrect evidence comes from brains that reach the floor. This avoids falsely assigning an error to the wrong mathematical fact.
